## 2. 问题与可证伪假设

1. 在原生 11、31、61 档评分上，D2 的序数分布目标是否比 CE 更适合 MAE？
2. 小数标签与宽评分范围下，相同分布表示的 CE/CDF 目标有何差异？
3. 差异是否与每档训练密度、相邻误差、尾部误差及标注者分歧相关？

这些是假设，不以 D2 获胜作为数据准入条件。不同 ASAP prompt 的主题、
rubric 和数量也不同；跨 prompt 的档位趋势只能作为关联，不能直接解释成
档位数的因果效应。五档标签乘以 25 仍然只有五档，不作为细粒度监督证据。

当前已核对：正式 Score 训练 75,000 条，测试 5,000 条，全为五档。
相同中位数解码下，D2/A4 的测试 MAE 为 0.4180/0.4148；
绝对误差 0/1/2/3/4 的计数分别为 D2 3171/1612/176/38/3、
A4 3190/1591/177/39/3。A4 同样保留序数 readout，普通 LoRA 也已有
cumulative-link Score head，因此不把这些对照描述成“无序 vs 有序”的纯比较。
证据为两者 `evaluations/epoch_1.test_in_domain.rank*.jsonl`，A4 需从原始
概率重算中位数，不能混用其历史 argmax 输出。

## 5. 连续标签的对等适配

原始 D2 公式是离散分布目标，现有正式数据入口只接受整数，普通 LoRA
评分入口还限制为五档。这些运行中的文件不修改；新增隔离的专项数据接口。
S3/S4 是明确标识的连续标签扩展，不能声称当前 D2 checkpoint 已支持任意实值。

建议预先固定完整输出网格：STS-B 为 0,0.1,...,5（51 点），WMT 为
0,1,...,100（101 点）。它是模型数值表示，不是把原始连续数据伪称为天然
51/101 类。原始 y 始终保留，测试误差始终对原始 y 计算。

若 y 位于相邻网格点 s_j、s_(j+1) 之间，双方使用同一插值目标：

    q_j = (s_(j+1)-y)/(s_(j+1)-s_j)
    q_(j+1) = 1-q_j，其他 q=0。

于是 sum(q_j*s_j)=y，无标签取整；令 Q_k=sum_(j<=k)q_j、
F_k=sum_(j<=k)p_j：

    S3: L = -sum_j q_j log p_j
    S4: L = c * sum_k w_k BCE(F_k, Q_k)
    w_k = (s_(k+1)-s_k)/(s_K-s_1)

两者都针对相同 q，没有给某一方额外人工标签。y 位于网格点时，S4 退化
为原 D2 离散公式。c 初始固定为 D2 的 3.0383850790577127；先做无优化
更新的梯度尺度检查，记录其由五档冻结而来的限制，不能依据测试结果调 c。

预测中位数作为 MAE 主输出，期望作为预先登记的连续诊断，不能看测试后
切换 headline。网格中位数有精度限制，需要报告“离真实 y 最近网格点”的
可实现最小绝对误差，不能把表示精度损失归因于 loss。STS-B/WMT 的最大
最近网格量化误差分别为 0.05/0.5。所有推理始终使用完整网格，无候选采样。
为比较表达能力，S3/S4 的网格、插值、解码和提示词全部一致。

## 7. 预先规定的报告

每来源/prompt 报 native MAE；跨范围汇总使用各面板等权的
NMAE = mean(|prediction-y|/(max-min))，不能把 0–100 的原始 MAE 与 0–5
直接混合。Score accuracy 仅辅助。另报 RMSE、Spearman、ASAP QWK、
分布指标、边界档位和大误差比例，以及训练/推理成本。
均值与中位数都留原始预测，但 MAE headline 不因结果改变规则。

标注分歧分析只在有真实多标注的 WMT 上做：按预登记的原始评分分歧分组，
比较 S3/S4 对均值的误差；不把方差自动解释成输入难度或标签错误。
粒度/分歧分组不重新训练，默认四次即可完成。使用成对 bootstrap，
WMT 按文档、STS 按相连句对组、ASAP 按 prompt 内 essay/重复组处理；
区间只表示固定模型的评测抽样不确定性，不是多 seed 稳定性。

如果需要直接检验“训练标签粗化”的因果效应，后续最多增加一对训练：
在同一原生多档位数据上只给粗分箱标签，输出仍保留完整原生档位，双方
都对箱内概率求和后监督，测试仍用原始完整评分支持。粗箱标签不能识别
箱内真实分布，需承认这一信息限制。这一对不属于默认四次预算，不能用
抽掉测试候选的方式替代，也不能从不同 prompt 间的差异直接推导该结论。
